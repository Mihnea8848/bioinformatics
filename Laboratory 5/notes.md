# Laboratory 5

### Exercise 1
Make an artificial DNA sequence of 200 up to 400 bases in length in which to simulate 3 to 4 transposable elements.

### Exercise 2
Implement a software application to detect the positions of the previous transposable elements from ex. 1. (start, end) within the created DNA sequence. Also take note of the graph.

### Exercise 3
Search for the transposable elements in a FASTA file instead of generating the sequence ourselves.
